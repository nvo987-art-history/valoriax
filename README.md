# VALORIAX

## Infrastructure de Transparence Institutionnelle

VALORIAX est une infrastructure ouverte de transparence institutionnelle connectée à l’écosystème NEXARIUM.

L’infrastructure soutient notamment :

- la documentation publiquement accessible ;
- l’intégrité opérationnelle ;
- la vérification cryptographique ;
- les cadres de responsabilité publique ;
- l’organisation sémantique des données ;
- la continuité archivistique ;
- la préservation de la mémoire institutionnelle ;
- les systèmes de documentation lisibles par machine.

## Écosystème

VALORIAX est connecté à l’écosystème NEXARIUM et soutient les projets associés à :

**NVO987 – Culture Visuelle Moderne et Contemporaine**

## Principes

1. Responsabilité
2. Vérification
3. Transparence
4. Préservation

## Vérification

L’infrastructure peut utiliser :

- des données sémantiques structurées ;
- des empreintes cryptographiques ;
- OpenTimestamps ;
- des systèmes d’archivage décentralisés ;
- des mécanismes de vérification interopérables ;
- des environnements lisibles par machine.
